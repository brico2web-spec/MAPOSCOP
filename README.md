# MapRoute Pro

نسخة مستقلة مستوحاة من فكرة تطبيقات تخطيط المسارات متعددة المحطات، وليست نسخة من كود أو واجهة Maposcope الأصلية.

## التشغيل
1. افتح `index.html` في متصفح حديث مع اتصال بالإنترنت.
2. اسمح بالموقع عند الحاجة.
3. أضف المحطات أو استورد Excel/CSV.
4. اضغط «تحسين المسار».

## Excel
يفضل أن يحتوي الملف على أعمدة:
- name
- address
- notes
- latitude
- longitude

يمكن استعمال العربية أيضا: الاسم، العنوان، ملاحظات.

## ملاحظات
- الخريطة من OpenStreetMap.
- تحديد العنوان يتم عبر Nominatim.
- حساب الطريق يتم عبر OSRM.
- البيانات تحفظ محليا في LocalStorage.
- لا توجد خوادم خاصة أو اشتراك داخل هذا المشروع.

## حدود النسخة
هذه نسخة Web/PWA قابلة للتطوير وليست APK جاهزا. لتحويلها إلى Android APK يمكن تغليفها لاحقا داخل مشروع Android/Capacitor.
